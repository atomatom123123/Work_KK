กรอบเวลาของข้อมูล:

ครอบคลุมเฉพาะข้อมูลช่วง พ.ค. - ก.ย. 2015 เท่านั้น

ช่วงเวลาไม่ได้รวมในรายงาน:

ยังไม่ครอบคลุมช่วงเทศกาลช้อปปิ้งใหญ่ปลายปี (เช่น 11.11, 12.12)

สถิติผู้เข้าชมรายชั่วโมง

What: ทราฟฟิกหน้าร้านพุ่งสูงที่สุดช่วง 20:00 - 22:00 น. (พีคสุด 192,000 events เวลา 21:00 น.)

So What: ผู้ใช้มี Intent และความพร้อมในการซื้อสูงสุดช่วงค่ำหลังเวลาทำงาน

Now What: จัดกิจกรรม Flash Sale หรือส่ง Push Notification คูปองนาทีทองเวลา 19:30 น.

สถิติแต่ละกระบวนการ

What: เกิด Drop-off สูงสุดในขั้นตอน View → Add to Cart โดยดรอปออกถึง 97.7% (จาก 2.39M เหลือ 54.5K)

So What: หน้าแสดงรายละเอียดสินค้า (Product Detail Page) อาจขาดข้อมูลการตัดสินใจ หรือปุ่มซื้อไม่ชัดเจน

Now What: ปรับปรุง UX/UI หน้าสินค้า เพิ่มรีวิว ยอดขายสะสม และปุ่ม "ซื้อทันที (Buy Now)"
